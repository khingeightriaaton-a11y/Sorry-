APOLOGY WEBSITE — QUICK START

1. Open index.html in your browser to preview the website.
2. Personalize the letter:
   - Open index.html in a text editor.
   - Find: const message =
   - Replace the sample letter with your own words.
3. Add your photos:
   - Put three photos inside the assets folder.
   - Name them exactly: memory1.jpg, memory2.jpg, memory3.jpg
   - JPG images are recommended.
4. Publish:
   - Upload the contents of this folder (index.html and assets folder) to your static website host.
   - Keep index.html at the top/root level so it opens as the homepage.

No server, database, or installation is required.
